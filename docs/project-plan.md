# Project Vision
RepairFlow CRM is a simple, affordable customer & repair management tool for independent mobile repair shops. It replaces paper registers with a digital system that tracks repairs, customers, parts, and revenue.

## Target Customer
- Small mobile/electronics repair shops (1–5 technicians).
- Shop owners who want to professionalize their service.
- Shops that currently use notebooks or Excel.

## Problem Statement
- No centralised record of repairs, leading to lost tickets, forgotten follow‑ups, and unhappy customers.
- Difficulty in tracking repeat customers and offering loyalty benefits.
- No analytics on revenue, popular repairs, or parts usage.
- Customers demand transparency – they want to know the status of their device (like parcel tracking).

## Features (v4)
- Dashboard with real‑time KPIs (revenue, pending, deliveries, etc.)
- Customer & repair CRUD with advanced search.
- **Timeline** – visual step‑by‑step progress for each repair (like Amazon tracking).
- **Technician Notes** – threaded notes for each repair.
- **Loyalty Program** – automatic detection of repeat customers, reward after 5 repairs.
- Export all data as JSON.
- Settings page (shop details, currency, theme placeholder).
- Robust error handling (corrupted data recovery).

## Non‑features (for now)
- User authentication (multi‑user).
- Cloud sync / backend.
- Mobile apps (PWA later).

## Future Roadmap
- PWA for offline access.
- Cloud sync with Firebase.
- SMS/WhatsApp notifications.
- Parts inventory management.
- Barcode scanning for IMEI.
