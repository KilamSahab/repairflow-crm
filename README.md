
## 🚀 Getting Started

1. **Clone or download** this repository.
2. Open `index.html` in a modern browser (use **Live Server** extension for best experience).
3. Go to **Settings** and enter your shop details.
4. Start adding repairs – all data is saved automatically.

## 📈 Usage

- **Dashboard** gives you a snapshot of your business.
- **Customers** page lets you search, filter, and manage all repairs.
- **New Repair** form includes technician‑specific fields (water damage, SIM received, screen lock).
- **Timeline & Notes** (click the info icon on any customer row) allows you to update repair progress and add internal notes.
- **Bill & Job Sheet** generate professional printouts.
